Ces polygones corrompus étaient affichés tels quels — rouge partiel visible, morceaux hors polygone.

Fixes implémentés dans l'atlas — À porter dans TERLAB

Fix A · PolygonEditor._hasSelfIntersect
Guard anti-croisement O(n²) dans drag

Avant chaque render() dans pointermove : snapshot prevPts → update → si _hasSelfIntersect(this.pts) → revert. Bloque visuellement le drag à la limite de validité. Applicable dans gabarit-engine mousemove et plan-masse-canvas pointermove.

Fix B · _drawEdgePill (port HOUSEG-SPEECH)
Capsule pointillée au hover d'arête

Port exact de drawInfluenceZone() (L3878 HOUSEG-SPEECH) en SVG : path M c1 L c2 A r r 0 0 1 c3 L c4 A r r 0 0 1 c1 Z, stroke-dasharray:5,4, fill orange léger, double flèche ⊥ + label "drag ⊥". Handle carré bleu → orange au hover.

Fix C · clipPath + evenodd offset
Offset toujours dans le polygone

Dual-layer SVG : clipPath sur polygone original → groupe cliqué → polygon fill-rule="evenodd". SVG fait tout le travail : débordements invisibles, boucles éliminées, rendu toujours propre. Aucun calcul de clipping nécessaire en JS.

Fix D · isConcave() + rendu différencié
Handles rouges pour coins rentrants 270°

Cross-product (prev→curr) × (curr→next) > 0 pour polygone CW → coin concave. Cercle rouge #e05030 pour les noeuds critiques. L'étudiant identifie immédiatement les jonctions L/T/X/Y à comportement particulier.

Fix E · Rotation globale + sous-forme
3 modes de rotation interactifs

Handle ↻ (cercle doré) : rotation libre autour du centroïde. Snap configurable 15°/45°. Mode pivot ancré (pivotIdx) : rotation autour d'un sommet fixe. Mode sous-forme (subshapeIdx[]) : rotation d'un sous-ensemble de vertices — les autres restent fixés.

Fix F · Edge drag ⊥ (vs insert vertex)
Push d'arête perpendiculaire correct

pointerdown sur handle arête → snap prevX/Y. pointermove → projeter delta souris sur normale ⊥ (nx=-ey/len, ny=ex/len) → déplacer exactement les 2 endpoints de proj*nx, proj*ny → guard anti-croisement → render. L'arête reste parallèle à elle-même.

Fix G · setPointerCapture
Drag fluide sans perte de focus

svg.setPointerCapture(e.pointerId) dans pointerdown → le SVG reçoit tous les événements pointer même si la souris sort. Évite les "drop fantômes" quand le drag est rapide. svg.releasePointerCapture dans pointerup.

Fix H · Pas d'offset partiel visible
Silence sur les dégénérescences

Suppression des zones rouges "offset partiel" et du label ⚠ textuel. Si l'offset est dégénéré, le clipPath+evenodd le gère silencieusement. Seule l'offset complètement effondrée (area<6px²) affiche une pastille orange discrète.
